# Projects

> Personal projects and open-source contributions.

## neofsn

[source.tube/spaceduck/neofsn](https://source.tube/spaceduck/neofsn)

A spatial filesystem navigator for macOS — a modern homage to SGI's FSN, the 3D UNIX interface from Jurassic Park. Built with SwiftUI and SceneKit.

## kfsn

[source.tube/spaceduck/kfsn](https://source.tube/spaceduck/kfsn)

Qt/KDE port of neofsn, built with Qt Quick 3D and KDE Frameworks 6.

## BSPRenderer

[source.tube/spaceduck/BSPRenderer](https://source.tube/spaceduck/BSPRenderer)

A DOOM-style software renderer ported to six languages: Swift, C++, Go, Python, Rust, and Zig.

## ls-rust

[source.tube/spaceduck/ls-rust](https://source.tube/spaceduck/ls-rust)

An implementation of ls written in Rust.

## kernel-ml-aufs

[github.com/bnied/kernel-ml-aufs](https://github.com/bnied/kernel-ml-aufs)

Mainline Linux kernel packages for RHEL/CentOS/OEL 7 & 8 with AUFS storage-driver support for Docker.

## kernel-lt-aufs

[github.com/bnied/kernel-lt-aufs](https://github.com/bnied/kernel-lt-aufs)

Longterm support kernel packages for RHEL/CentOS 6 & 7 with AUFS support for Docker.
